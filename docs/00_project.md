# Kancolle Senka Planner

## 项目简介

Kancolle Senka Planner 是一个完全本地运行的 HTML 工具，用于《艦隊これくしょん》（艦これ）的战果记录、战果规划、历史数据保存与统计分析。

项目以长期使用为目标，强调数据可持续积累、规划分析与可视化展示，而非一次性的计算工具。尽可能减少浏览器缓存清理导致的数据丢失风险。

整个项目无需服务器、无需数据库，可直接在浏览器运行，并支持部署至 GitHub Pages 等静态网页环境。

---

## 项目目标

- 建立长期稳定的战果历史数据库。
- 提供战果规划与目标管理能力。
- 提供当期数据统计与可视化分析。
- 保留历史奖励信息，便于长期查询与回顾。
- 保持完全离线可使用，仅依赖浏览器本地存储。
- 保持简单易维护，方便未来持续扩展新功能。
- 优先保证本地数据安全，降低浏览器缓存丢失造成的数据风险。

---

## 主要功能

### 战果规划

- 每日战果记录
- 当前战果统计
- 日均战果计算
- 战果目标设定
- 剩余目标计算
- 所需日均计算

### 战果相关数据管理

- EO（Extra Operation）完成情况
- 战果 Ex 任务完成情况
- 活动期间战果任务记录（按需使用）

### 数据统计

- 当前月份数据统计
- 历史月份统计
- 战果趋势分析
- 数据可视化展示

### 历史资料保存与信息追加

- 每月最终战果记录
- 追加记录战果奖励区间（一群、二群、三群、联合等）
- 追加记录当月奖励内容记录
- 历史查询

---

## 技术目标

- 数据默认保存于本地。
- 优先采用浏览器可持久化存储方案（如 IndexedDB）。
- 提供自动保存机制。
- 提供 JSON 导入导出。
- 允许用户建立多个备份。
- GitHub Pages 仅作为静态部署方案，不保证所有功能可用。

---

## 开发原则

- 优先保证数据安全与长期可维护性。
- 优先保证界面清晰易读。
- 功能逐步增加，避免一次实现过多复杂功能。
- 为未来扩展预留数据结构与模块接口。

---

### 设计理念

- 本项目定位为长期陪伴型工具，重点在于帮助玩家持续积累数据、进行规划与复盘，而不是追求复杂的数据分析或自动化采集。所有功能均应优先服务于长期记录、查询和规划。
