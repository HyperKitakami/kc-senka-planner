# Kancolle Senka Planner

《艦隊これくしょん》的战果记录、规划与统计工具。

**完全本地运行**——无服务器、无数据库、无构建步骤。双击 `index.html` 即可离线使用，数据只存在你自己的浏览器里，不会上传到任何地方。

> 本文件是**用户手册**，只讲「怎么用」。
> 业务规则、界面设计与技术实现在 [`docs/`](docs/) 中。

---

## 快速开始

1. 下载或克隆本项目。
2. 双击 `index.html`，用浏览器打开。
3. 到「设置」页填入你的**服务器**（用于生成人事表链接）。
4. 到「战果记录」页录入今天的出击战果。

没有安装步骤，不需要服务器，也不需要联网。推荐使用新版 Chrome / Edge / Firefox。

---

## ⚠️ 先看这里：数据存在哪里

所有数据保存在**你当前浏览器**的 IndexedDB 中（库名 `kc-senka-planner`）。

**浏览器清理站点数据会一并清除，且无法找回。**

因此请定期到「数据管理」页 **导出 JSON 备份** 到文件——这是唯一能扛住清缓存的手段。页面内的「本地备份」与主数据存放在同一处，只能防误操作，防不了清缓存。

> **poi 快照单独存放。** 从 poi 同步来的数据快照存在浏览器的 localStorage 里，
> **不参与导出 / 导入**，清理站点数据同样会丢失。它只用于展示建议值、战果线与任务比对，
> 可在「设置」页单独清除；清除快照不会影响任何业务数据。

> **换浏览器 / 换电脑**：数据不会跟着走。请先在旧环境导出 JSON，再到新环境导入。

## 界面总览

共 9 个页面，左侧导航切换。

| 页面 | 用来做什么 |
| --- | --- |
| **首页** | 总览面板：战果进度条、11 张可配置卡片（顺序 / 尺寸 / 显隐）、近 14 天趋势、最近数据摘要 |
| **周期查询** | 时间边界速查：任务刷新周期与战果结算周期还剩多久 |
| **战果记录** | 每日出击战果的录入 / 修改 / 删除，按月份浏览；列表 / 日历双模式 |
| **战果任务** | EO / EX / 活动 / 自定义任务，按周期管理完成状态与规划池 |
| **战果规划** | 设定目标，查看所需日均与预计月底战果 |
| **数据分析** | 每日增长趋势、月度比较、战果构成、战果线对比 |
| **历史归档** | 每月最终结果、奖励区间与奖励装备的长期留存 |
| **数据管理** | 导出 / 导入、本地备份、清空 |
| **设置** | 主题、首页布局、默认规划方式、服务器、poi 快照管理 |

## 各页面用法

### 首页

进入即是总览。默认展示战果进度、当月关键指标与近期趋势。

想调整布局：点「**编辑布局**」进入编辑模式，此时可以**拖动卡片排序**、按**小 / 中 / 大**改尺寸、以及显隐卡片；调整完退出编辑模式即可。

平时首页是纯展示的，不会被误拖。面板卡（日历 / 趋势 / 摘要）与统计卡同处一个网格，一样可排序可缩放；窄屏下大号卡片自动退化为整行。设置页另有一套等价的、可用键盘操作的控件。

### 周期查询

想确认「这个月的任务什么时候刷新」「战果算到哪一刻为止」时用这一页。

页面分两栏，分别显示**任务刷新**与**战果结算**的剩余时间，可切换查看不同周期的边界。

> 这两种边界是**两套不同的时间**，用途也不同，别混用。完整说明见 [`docs/04_calculation.md`](docs/04_calculation.md) §四。

### 战果记录

录入每日**出击战果**的位置。

- **两种录入模式**：列表模式适合逐日修改，日历模式适合快速补齐整月。
- **按月份浏览**：可切换月份查看/补录历史数据。
- **补录**：可直接选中历史日期录入，统计会自动重算。

> 本页**只**记录当日出击战果。EO / EX / 活动任务、继承战果都不写在这里，请分别到「战果任务」与「战果规划」页处理。

### 战果任务

管理所有战果任务：EO、EX、活动，以及你自己新增的任务。

- **任务卡片分组展示**：EO 卡片、预设 EX 任务卡片、活动与自定义任务。
- **勾选完成**：按周期维护完成状态，跨周期会自动重置。
- **规划池**：把「计划完成但还没完成」的任务加入规划池，用于规划计算；规划池不影响任务的实际完成状态。
- **任务进度节点**：部分任务（如 EX 季常）拆成了多个海域节点，逐个点选即可，全部达成后任务自动标记完成。
- **名称列显示游戏内完整任务名**，鼠标悬停可看简称。

### 战果规划

设定当月目标，查看还差多少、每天需要打多少。

- **双口径**：可分别查看「实际」与「综合」（含规划池任务）两种统计口径。
- **关键指标**：当前战果、距目标仍需战果、自然日均、所需日均、预计月底战果。
- 目标只作规划用途，不会影响历史数据。

### 数据分析

- **每日增长趋势**：当月逐日出击战果变化。
- **月度比较**：可自选要比较的数据项，横轴可覆盖 1～24 个月。
- **战果构成**：把当前战果拆解为各来源。
- **战果线对比**：把当月累计战果与各奖励线放在一起看（需要 poi 快照）。

### 历史归档

每月月末把结果「**存档**」下来长期保留。

- 记录内容：当月最终战果、排名、奖励区间（联合 / 一群 / 二群 / 三群 / 特务 / 田选）、是否联合第一、奖励装备、备注。
- **列表支持分页**（每页 10 / 20 / 50 条）与**筛选**（按年份、奖励区间）；筛选不会影响上方的统计卡。
- **人事表**：设定服务器后，可一键打开该月的官方人事表图片（在新标签页打开，程序本身不会发起网络请求）。
- 若某月已存在归档，再次新建时会弹出**覆盖警告**，确认按钮会延迟几秒才解锁，避免手快误覆盖。

> 「计算战果」是实时算出来的展示值，**不会写进归档**；归档只是结果快照，不参与统计计算。

### 数据管理

- **导出**：把全部数据导出为 JSON 文件，便于长期保存或迁移。
- **导入**：支持**整体替换**与**合并导入**两种方式；文件含版本号，会按版本顺序自动迁移。
- **本地备份**：在同一浏览器内留副本，用于防误操作。
- **清空**：删除全部数据，请谨慎。

> 迁移失败会**阻断导入并保留原文件**，不会静默丢数据。

### 设置

- **主题**：浅色 / 深色。
- **首页卡片**：顺序、尺寸、显隐（与首页「编辑布局」等价）。
- **默认规划方式**：规划页默认使用哪种统计口径。
- **服务器**：用于生成人事表链接（共 20 个服务器）。
- **poi 快照管理**：查看与单独清除 poi 快照。
- **关于**：程序版本与数据结构版本。

## poi 数据接入

本工具可以读取 [poi](https://github.com/poooi/poi) 战果插件(poi-plugin-achievement)的数据文件，为你提供：

- **每日建议值**：在战果记录页给出该日应达到的战果，并支持**一键填充**空白日期。
- **战果线对比**：在数据分析页把当月累计与各奖励线画在一起。
- **任务完成状态批量同步**：自动比对 poi 记录的 EO / EX 季常完成情况，省去手工勾选。

### 怎么用

1. 在 poi 中找到战果插件的数据文件（通常位于 `%APPDATA%/poi/achieve/achieve.json`）。
2. 到本工具的「战果记录」页（或「战果任务」页），点同步按钮。
3. 在弹出的文件选择框中**手动选中该文件**。

### 为什么每次都要手动选文件

浏览器出于安全考虑，不允许网页自行读取本地任意路径。所以同步**完全手动触发**，本工具无法也不会有后台自动读取。

> 同步得到的是**快照**，存在浏览器 localStorage 中，不参与导出导入。它只用于展示建议值、战果线与任务比对；清除快照不会影响任何业务数据。

## 常见问题

**数据会不会丢？**
保存在浏览器 IndexedDB 里。正常使用不会丢，但**清理浏览器站点数据会全丢**。请定期导出 JSON 备份。

**换电脑 / 换浏览器怎么办？**
在旧环境「数据管理」页导出 JSON，在新环境导入。

**清除了浏览器数据，能恢复吗？**
不能。只有导出过的 JSON 文件能恢复。

**为什么 poi 不能自动同步？**
浏览器不允许网页自行读取本地路径，这是安全限制，只能手动选取文件。

**任务完成状态为什么跨周期自己清了？**
任务完成状态是按周期（日常 / 周常 / 月常 / 季常 / 年常）维护的，进入新周期会重置。

**首页卡片被我拖乱了，怎么恢复？**
再次进入「编辑布局」拖回原位，或在「设置」页调整卡片顺序。

**归档月份填错了怎么办？**
在历史归档页删除该月归档后重新创建。
